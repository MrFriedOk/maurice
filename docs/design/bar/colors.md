# Colors
What colors am I using, where do they come from?

## Singleton
Singletons in QML are limited to one per engine, they can integrate other languages and file formats (like json) to do stuff. 
The `Colors.qml` file is a singleton, it is created by (https://github.com/InioX/matugen)[matugen] (and its input is configured by me) and dicatates different colors used across the entire project. 
All these 'properties' can be referenced globally, makes it really easy to set colors.. and you'll be doing that a little bit for a rice.
