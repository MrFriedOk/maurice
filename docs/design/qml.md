# QML
On the decision to use QML (or more specifically, Quickshell), what it does and how it works.

## Why?
I chose QML because Quickshell uses it and I know how cool Quickshell can be. It's like the difference between choosing to build a PC or buy one prebuilt.. I guess one's preferences would influence that decision but *I* think it's more fun! <(￣︶￣)>

## What?
[^1]Quickshell is a 'toolkit' for building a desktop shell. It uses QtQuick configured with QML.
### Features
- 'Hot-reloading', allows you to make config changes and the shell adapts without reloading manually.
- Wayland integration (the future of linux desktop)
- MPRIS compatible (media control).
- Greetd, a desktop manager. Will not be used in this project but I will come back to this later.

[^1]: https://quickshell.org/docs/v0.3.0/types/Quickshell/Variants/
